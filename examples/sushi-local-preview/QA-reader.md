## 展示与计算口径

- 包络视图一次显示一条超边。上一条、下一条和超边列表用于切换；节点选择将列表筛为该节点的关联超边。显示全部取消此筛选，重置清除选择和拖动。
- 节点参与度为全图不同超边 ID 数。圆面积在可读下限和上限间随参与度变化，标题字数不决定此视图中的圆面积。
- 成员数按不同节点 ID 去重；共享节点数为本超边中同时属于其他超边的节点数；关联超边数为通过任意共享节点关联的其他超边数，每条只计一次。
- 多角色成员仍保留所有角色，但不重复计算结构指标。筛选、选择和切换界面语言不改变全局指标。
- 并列值显示并列名次。此例所有超边共享苏轼，关联超边数均为 17；不把这一指标硬凑成有区分度的排名。列表同时支持成员数和共享节点数排序。
- 结构指标不代表历史地位、知识价值、证据质量或因果重要性；包络圆大小不编码超边重要性。
