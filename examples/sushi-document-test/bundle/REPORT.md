# 《苏轼传》高阶知识图谱示例

- 节点：38
- 原生关系：10
- 原生无向超边：10
- 原生无向二元关系：0
- 成员关联：49
- 具有来源记录的关系：10/10

本示例使用 `general/hypergraph` 结构，将人物、事件、时间、地点、作品、
政策和群体角色保留在同一条多元关系中。所有语义结构均标记为
`model_predicted`，只表示 Codex 根据输入文档生成的候选结构。

输入文档是一份用户提供的二手传记材料，尚未进行历史事实核验。因此，
“来源记录”只证明该说法出现在文档中，不证明说法本身真实。晚年轨迹拆成
“贬谪惠州”“贬谪儋州”“北归”三条事件超边，直接连接人物、时间和地点；
`trajectory_index` 只表示年代顺序，不表示边的方向。该数据包没有原生二元
关系，界面不会生成二元投影或辅助节点。
